## 2. 三种形态与触发条件

1. **静态（无输入）**：页面一打开、用户什么都没给 ⇒ **图1/图2/图3 直接出 11 弹标称散点**，
   **不解算、不扫网格、秒级、离线可出**。
   （现状差距：图2 默认仍要扫 1032 工况 ⇒ 必须补"静态=只出 11 点"的形态。）
2. **动态（有输入）**：用户提交工况（环境 + 基准弹 + 想定）⇒
   * **沙盒（图4）置顶**，严格随该输入；
   * **图1/图2 加等时线**、**图3 加等时面**；
   * **一次提交，四块一起出**（现状是"一个任务一张图"）。
3. **图4**：只有动态形态；没有工况 = 不显示。
