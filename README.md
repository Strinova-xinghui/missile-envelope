# 导弹包线图 · 对比弹池（纯静态站）

**线上地址：<https://strinova-xinghui.github.io/missile-envelope/>**

把 War Thunder 的主动雷达/红外制导空空导弹放同一张图里比"存能能力"的**纯静态**小站：
选一个对比弹池（默认我们的 11 弹），三张图的坐标轴与点**在浏览器里实时重画**，不连任何后端。

| 图 | 横轴 | 纵轴 | 内容 |
| --- | --- | --- | --- |
| 图1 | 理想总增速 ΔV | 简化弹道系数 β（≡BC） | 各弹标称点，轴随所选弹池自适应 |
| 图2 | β（直飞保能） | ginv = 1/γ（转向能力） | 等 `n*` 线（临界过载）叠加 |
| 图3 | ΔV / β / ginv 三轴 | — | 可旋转/缩放的 WebGL 散点；角部**红=三轴最小角（差区）、绿=三轴最大角（好区）** |

* 目录共 **168 个预设（159 可算）**；9 条（PL-15、AIM-54 系）用 `propulsion*` 多发动机族，
  本项目权威两级公式不覆盖 ⇒ 列表里**置灰**，原因写「需要动态解算」。
* 数值全部由内核 blk **现算**（ΔV = 齐奥尔科夫斯基分级求和；BC = 干重/(SD·CxK)；γ 见下），
  与既定权威表逐值一致。
* **本仓库只放构建产物**（孤儿 `gh-pages` 分支，零历史）：不含源码、**不含任何 War Thunder 游戏数据**。
* 口径说明见站内 **`method.html`**（为什么纵轴取 γ 的倒数、单位过载下 γ 的含义等）。
