看图前必读：γ 与两张图的口径

本页只讲一件事：图2 纵轴的 γ（诱导阻力 / 升力那一项）是怎么来的、怎么读。

内核 python-game-6dof-v1 · wt-missile 2.59.0.28（sha256 dad09cae…） · 工况：发射距离 50 km（水平） · 载机高度 10 km · 载机 300 m/s · 目标方位 0° · 参考工况 10 km / 800 m/s

0. 这两张图是什么

图1 画 ΔV–β（横轴理想总增速、纵轴弹道系数口径）；图2 画 β–ginv（横轴直飞保能、纵轴转向能力）。 两图都是不含等时线的静态版：只放 11 枚弹的标称点，不随工况重算。

本图册不含程序、不含任何游戏数据：它是成品图与口径说明。

1. β 是什么（一句）

β = m燃尽 / (SD · CxK)　[kg/m²]

就是通常说的弹道系数（BC）口径，直飞保能，越大越好。其中 SD = π·d²/4 直接取求解器的 drag_area，CxK 是零升阻力系数。

2. γ 是什么（本页的重点）

2.1 一句话

γ 是把「用升力换取过载」折算成「诱导阻力损失」的单一系数，单位 [kg/m²]， 越大越差（转向越贵）。

2.2 定义

γ = m燃尽 · SD · CxK · CxAoA / (SL² · CyK²)　[kg/m²]

逐项：SD = π·d²/4（drag_area，口径面积）、 SL = 0.3 · d · L · wingAreaMult（lift_area，升力面积）、 CxK 零升阻力系数、CxAoA 诱导阻力系数、CyK 升力线斜率、 m燃尽 燃尽质量。两个面积都直接取求解器的量，不另造口径。

2.3 为什么说它「对应单位过载」

求解器的阻力式把阻力写成两项（q 是动压、M 是马赫数、α 是迎角）：

D = q · SD · CxK · [ f(M) + CxAoA · F(M) · sin²α ]

升力一侧是 L = q · SL · CyK · sinα，而过载按定义是 n ≡ L / (m · g0)； 把 sinα 用 n 表示、再整式除以质量，就得到按过载表达的减速度损失：

a_loss = q · f(M) / β　+　γ · F(M) · (n · g0)² / q
└── 基础项（∝ q）──┘　└──── 诱导阻力项（∝ 1/q）────┘

⇒ 第二项的系数就是 γ：在 n = 1（单位过载）时它就给出该弹的诱导阻力损失水平。 n 倍过载时按 n² 增长（因为 sinα ∝ n）。两项对动压的依赖方向相反， 这就是「高空高速看 β、低空缠斗看 ginv」的根源。

2.4 为什么它能当坐标轴（是弹的固有量）

β、γ 都用标称值：f(M)、F(M) 这两个马赫修正留在「损失」那一侧， 不并进系数本身；质量取燃尽质量。于是它们与高度、速度、过载都无关，只由弹自身几何与系数决定 —— 否则同一枚弹每隔一个马赫数就换个值，没法当坐标轴。

2.5 为什么图上画的是 ginv = 1/γ

β 大 = 好，γ 大 = 差，两者方向相反。取倒数之后两根轴同为「向上＝更好」， 右上角就是天然的双优区，读图不用再在脑子里翻符号。

ginv 只是读数方式：γ 的定义一个字没改，ginv = 1/γ（单位 [m²/kg]）， 换算只在唯一一处完成。

2.6 由它派生的几个量（读等 n* 线要用）

  • Q = √(β · γ · F/f)　机动敏感度 [kg/m²]
  • n* = q / (Q · g0)　临界过载 [G]：机动损失恰好等于基础损失的那一点，越小越「贵」
  • R = (n / n*)²　机动惩罚比（R = 1 时两项等量）
  • β_eff = β / (1 + R)　把机动折回 BC 口径的等效弹道系数

在 ginv 轴上，同一 n* 的点连起来是一条过原点的直线（因为 γ ∝ β）， 所以图2 里的虚线族是直线而不是曲线。

2.7 适用边界（不要越界引用）

上述关系只在升力线性段成立（CyK · sinα ≤ CyMaxAoA），并且是 准平衡、无角速度的假设；n 取的是实际气动过载。

3. 一个例子：PL-12

β = 3,078.1 kg/m²，γ = 56.60 kg/m²， ginv = 0.01767 m²/kg； 在参考工况（10 km、800 m/s（Ma 2.660、q = 132,364 Pa））下 n* = 18.36 G。

弹池范围：β ∈ [2,567.0, 3,683.9] kg/m²、γ ∈ [53.49, 91.19] kg/m²、 ginv ∈ [0.01097, 0.01869] m²/kg、ΔV ∈ [820.5, 1,099.5] m/s。

4. 已知限制

  • 模拟器自身的绝对阻力水平未标定：β/γ 是标称系数，不等于实测气动数据。
  • ΔV/BC 与乘数之间是等效映射（同样总增速 / 同样弹道系数），不代表真实气动外形。
  • 图是仿真结果，不是游戏内实测。
